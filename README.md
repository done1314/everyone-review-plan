# 人人复习计划

独立的静态 Web App。打开后从空白计划开始，适合自行安排任何课程或项目。无需注册，记录保存在当前浏览器。

[打开 Web App](https://done1314.github.io/everyone-review-plan/)

## 使用

1. 在“设置”中修改计划名称。
2. 在“计划”中添加任务，填写任务名称、分类、开始日期和默认专注时长。
3. 点击“添加根目录”创建学习单元，填写名称和天数。根目录中的“＋ 子目录”可继续细分，并分别设置天数。子目录天数之和应等于所属根目录天数。
4. 任务总天数自动等于所有根目录天数之和。任务可随时编辑、重排目录和更改计划。
5. 在“今天”使用番茄钟，上传学习照片后打卡；可提前完成或将今天设为休息日。
6. 在“进度”查看每日、每周或每月的分类专注时长。

支持添加到手机桌面和离线打开。数据只保存在当前浏览器的 localStorage 中，清理浏览器数据或更换设备后不会自动同步。
